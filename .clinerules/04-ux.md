# UX

## Theming

- Theme through `material_ui` only (`07-flutter-client.md`); never hardcode colours — use `Theme.of(context)` / `colorScheme`.
- Verify dark mode on every screen you touch. The theme guard exists because a wrong import breaks it silently.
- Reuse fork widgets: `KitchenOwlFab`, `LoadingElevatedButton`, `KitchenOwlSwitch`, `askForConfirmation`, `showSnackbar`.

## States

- Every async view needs loading, empty and error states — not just the happy path.
- Empty states say what to do next, in localized copy.
- Show failures in a localized snackbar; never swallow an error silently.
- Keep layout stable while loading: no jumping headers, no zero-height placeholders.

## Offline

- Queued writes are visible: pending and expired states, never a silent drop (`App.notifyOfflineQueueExpired`).
- Never block the UI on a network call; the queue replays in the background.
- Forced-offline mode keeps the app usable for browsing cached content.

## Interaction

- Destructive actions confirm first (`askForConfirmation`) and report the result.
- Icon-only buttons get a `tooltip` and a semantic label.
- Check mobile and web widths: no overflow, no clipped labels, tap targets ≥ 48dp.

## Copy

- Sentence case, imperative, no upstream product names.
- Dates and numbers go through the localized formatters, never `toString()` on a `DateTime`.
